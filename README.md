# tinytowngen
タイルパターンから都市の上空画像（PNG）を作成する Swift 製 CLI。
`Resources/patterns.png` と `Resources/tiles.json` はビルド時ではなく **ソースに base64 で埋め込み済み** なので、実行時にリソースファイルは不要です。

## ビルド

```sh
swift build -c release
.build/release/tinytowngen --help
swift test
```

リソースを差し替えたら `Scripts/embed-resources.sh` を実行して `Sources/TinyTownCore/EmbeddedResources.swift` を再生成してください。

## 使い方

```sh
tinytowngen -l <配置|@file|@-> -o <出力.png> [-g 13x7] [-s シード] [--border] [--scale n] [-v]
tinytowngen -r <パート列|@file|@-> -o <出力.png> [-g 13x7] [-s シード] [--border] [--scale n] [-v]
tinytowngen --list-variants <C|CL|CR|CT|CB|B|all> -o <一覧.png> [--scale n]
```

| 引数 | 必須 | 説明 |
|---|---|---|
| `-l, --layout` | ✔ | 配置パラメーター（下記）。`@path` でファイルから、`@-` で標準入力から読み込み（空白を含む値は常にインライン扱い。空白を含むパスは `-l @- < "path"`） |
| `-r, --raster` | (✔) | `-l` の代わりに、パート列（raster）で街を指定（下記）。`-l` / `-r` のどちらか一方が必須 |
| `-o, --output` | ✔ | 出力 PNG ファイル名 |
| `-g, --grid` | | タイルの並び `WxH`（既定: 配置内の `@grid`、なければ `13x7`） |
| `-s, --seed` | | 商業地区・工事中のバリエーション選択用シード（既定: 配置内の `@seed`、なければ 1） |
| `--border` | | 外周にも 1px の道路を描く |
| `--scale` | | 出力を整数倍に拡大（確認用、既定 1） |
| `-v, --verbose` | | 解決された配置とバリエーション番号を stderr に出力 |
| `--list-variants <P>` | | 街の代わりに、パターン P（C, CL, CR, CT, CB, B）の全バリエーションを `#n` 番号付きで並べた一覧画像を出力。`all` で 6 パターンを黄色の見出し付きで 1 枚に（`-o` 必須、`-l` とは併用不可） |
| `-h, --help` | | ヘルプ（AI エージェント向けに文法・エラー条件を網羅） |

### 座標と寸法
- 1 タイル 19×19px、タイル間に 1px の道路（`#777777`）。既定では外周に道路はありません。
- タイル `{x,y}` は左上 0 起点。画像サイズは `(W*20-1) × (H*20-1)`（13x7 → 259×139）。
- 道路線は縦が `1..W-1`、横が `1..H-1`。道路 k はタイル列（行）k-1 と k の間。
- `--border` を付けると外周に 1px の道路が加わり、全座標が +1px ずれて画像は `(W*20+1) × (H*20+1)`（13x7 → 261×141）。グリッド端まで届く防火帯・水路は外周道路を越えて画像の端まで延びます。

### 配置パラメーター

空白・改行・`;` 区切りのトークン列。単語の先頭にある `#` から行末まではコメント（`C{1,2}#3` はバリエーション指定、`C{1,2} #3` はトークン＋コメント）。

| 書式 | 意味 |
|---|---|
| `C{x,y}` / `C1{x,y}` | 商業区画（1 タイル） |
| `CL{x,y}` `CR{x,y}` `CT{x,y}` `CB{x,y}` | 商業区画のハーフ（左・右・上・下）。`CL`+`CR` などで 1 タイルを共有 |
| `B{x,y}` | 工事中 |
| `Un{x,y}` / `UWxH{x,y}` | 緑地。左上 `{x,y}`、内部の道路を跨ぐ。サイズ: `U1` `U2` `U3` `U1x2` `U2x1`（`U1x2` を 90° 回転） |
| `F{r}` / `F{r,x0-x1}` | 防火帯。横方向の道路 r を置換（範囲指定で部分のみ） |
| `W{c}` / `W{c,y0-y1}` | 水路。縦方向の道路 c を置換。グリッド内で途切れる端は閉じた形で描画し、1 行だけ（`W{c,y-y}`）なら短い水路になる |
| `C*` / `B*` | 残りの空きタイルを埋める（`C*` は片側だけのハーフも補完） |

- 防火帯と水路が交差し、水路が防火帯の両側に続く場合は、防火帯が橋として水路の上を渡る形で描かれます。水路が防火帯で終わる場合は防火帯の下に潜ります。
- 配置の中に設定を書けます（ディレクティブ。値は次の単語）: `@grid WxH`、`@seed N`、`@border`。コマンドラインの `-g`/`-s` が優先、`@border` と `--border` はどちらか指定で有効。ファイルに書いておけばそのファイルだけで同じ画像を再現できます。不明なディレクティブ・値の欠落/不正・同じディレクティブの重複はエラー。
- C/CL/CR/CT/CB/B の x, y は `a-b` の範囲指定可（矩形に敷き詰め）: `C{0-12,0-6}`
- `#n` を付けるとバリエーションを固定: `C{3,2}#5`

### raster 指定（`-r`）

ストリームで流し込めるよう、街をパートの並びで指定します。1 タイルは 2x2 パートで、W×H のグリッドでは (2W)×(2H) 個のパートを、上の行から順に左から右へ渡します（改行・区切りは任意、`C1C3` と `C1 C3` は同じ。`#` から行末はコメント）。

| パート | 意味 |
|---|---|
| `C0` | 単独の商業パート（ブロックの 1/4） |
| `C1`〜`C4` | 同じタイル内の隣のパートと単位ベクトルで連結: C1=(1,0) 右、C2=(0,-1) 下、C3=(-1,0) 左、C4=(0,1) 上。`C1 C3` = 水平ハーフ、`C2`/`C4`（上下）= 垂直ハーフ、`C1 C2 / C4 C3` = タイル全体 |
| `B0` | 工事中パート。1 タイルの 4 パートすべてで工事中タイル、それ以外は単独パート |
| `U0` | 緑地パート。タイル単位の長方形が 1 つの緑地（1x1, 1x2, 2x1, 2x2, 3x3 タイル）。隣接する U0 は 1 つの領域として扱う |

防火帯・水路は道路の置き換えなのでパートとして数えません。

| 記号 | 位置 |
|---|---|
| `F0` 行 | タイル行の境界（パート行 2, 4, … の直前）に、1 タイル `F0F0` × W タイル = 2W 個。水平方向のみ |
| `R0` | パート行の中で、隣り合うタイルの間（パート列 1\|2, 3\|4, …）。`R0R0`（タイルの 2 つのパート行に 1 つずつ）で 1 タイル分。縦に続くタイル行は 1 本の水路。垂直方向のみ |

```sh
# 2x2 タイル = 4x4 パート
tinytowngen -g 2x2 -o raster.png -r "C1C2 C0B0 C4C3 B0C0 F0F0F0F0 U0U0 R0 C2C2 U0U0 R0 C4C4"
```

エラー（終了コード 1）はまとめて報告され、各項目にトークン番号（F/R を含む通し番号）、パートの行・列、タイル座標と位置、修正方法が付きます。

- パート数（F/R を除く）が (2W)×(2H) と一致しない（不足位置・余分なトークンを表示）
- 不明な記号、C の数字が 0〜4 以外、U/B/F/R の数字が 0 以外
- C1〜C4 のベクトルがタイル外・連結パート以外を指す、または上記のブロック形にならない
- F がタイル行境界の 1 行になっていない・個数違い、R0 が道路上にない・`R0R0` の片方だけ
- U0 の領域がタイル単位の長方形でない・対応サイズがない、F 行や R0 が緑地を横切る（外周に接するのは可）

### シード
`#n` を付けない場合、バリエーション番号 = `(タイル数 mod シード + 指定順番) mod 候補数`。
指定順番はパターン（C, CL, CR, CT, CB, B）ごとに指定順で 0 から数えます。
候補数: C=63, CL=12, CR=12, CT=20, CB=20, B=2。各 `#n` の見た目は `--list-variants` で確認できます:

```sh
tinytowngen --list-variants C -o variants-C.png --scale 4
tinytowngen --list-variants all -o variants.png --scale 4
```

### エラー（終了コード 1）
- グリッド外にはみ出す指定
- 同じタイル（ハーフの場合は同じ半分）への重複指定
- 緑地を防火帯・水路が横切る指定（緑地の外周に接するのは可）
- 未知のパターン、書式不正、存在しない緑地サイズ・バリエーション（複数行の配置では `line N:` 付きで表示）

オプション不足・読めない `@` ファイル・空の配置など、使い方の誤りは終了コード 2。

### 例

```sh
tinytowngen -g 13x7 -s 5 -o city.png \
  -l "U3{0,0} U2{9,4} B{5,2} CL{6,2} CR{6,2}#3 F{3} W{4,4-6} C*"
```

配置をファイルに書く場合:

```sh
cat > town.txt <<'TXT'
@grid 13x7 @seed 5
# parks
U3{0,0} U2{9,4}
F{3}            # boulevard
CL{6,2} CR{6,2}#3; B{5,2}
W{4,4-6}
C*
TXT
tinytowngen -o city.png -l @town.txt
```
